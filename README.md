# Mutagen Fundamentals and Troubleshooting for DDEV

A presentation covering Mutagen fundamentals and troubleshooting techniques for DDEV.

## 🎯 View the Presentation

**👉 [View Live Presentation](https://rfay.github.io/mutagen-fundamentals-and-troubleshooting-presentation/)**

## 🧪 Local Development

To preview the presentation locally:

```bash
npm start
```

This will start a local server at http://localhost:8000

## 📝 Editing the Presentation

The presentation is written in Markdown in `slides/mutagen-fundamentals-and-troubleshooting-presentation.md`.

- Use `---` to separate slides
- Use `--` for vertical slides
- Add images to the `images/` directory
- Customize styling in `css/custom.css`
